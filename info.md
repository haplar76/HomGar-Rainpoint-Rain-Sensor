# Homgar Smart Garden Integration

Connect your RainPoint Smart+ garden devices to Home Assistant.

## Features
- Monitor soil moisture, temperature, and humidity
- Track rain detection and amount
- Monitor device battery levels
- View watering zone status
- Automatic device discovery

## Supported Devices
- RainPoint Smart+ Irrigation Display Hub
- RainPoint Smart+ 2-Zone Water Timer  
- RainPoint Smart+ Soil & Moisture Sensor
- RainPoint Smart+ Rain Sensor
- RainPoint Smart+ Humidity Sensor
